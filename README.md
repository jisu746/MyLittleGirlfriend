# 여자친구 머리카락 청소하기 🧹

여친 몰래 방을 치워주려다 바람을 검거하게 되는 1인칭 3D 웹 미니게임.

## 스토리
토요일 아침, 여자친구가 먼저 외출한다. "나도 좀 이따 나갈게~" 해놓고 몰래 남아서, 방에 떨어진 머리카락을 싹 치워 **서프라이즈**를 해주기로 한다.

- 시간 제한 없음. 틀린그림찾기처럼 방 곳곳(가구 밑, 카펫 위)에 숨은 머리카락을 전부 찾아내자. 막히면 💡 힌트(20초마다).
- 침대·소파 밑, 카펫·화분 밑 어딘가에 여자친구 것이 아닌 **꼬불꼬불한 털이 딱 하나** 숨어 있다. 주우면 속마음이 흘러나온다. "(…이건 어디서 나온 거지?)"
- 그리고 얼마 뒤, 예고 없이 문이 열린다. 여자친구가… 낯선 남자와 함께 들어온다. (대사는 둘이 내 화면에 보일 때 시작된다.)
- 그 뒤로는 도구 바에 🔨 망치 · 🔥 라이터 · 😢 울기가 생긴다. 청소 도구와 번갈아 들며 하고 싶은 대로 하다가, 문으로 나가면(E) 끝. 가장 많이 한 행동으로 엔딩이 정해지고 **엔딩 도감**에 모인다.

## 조작
| 동작 | PC | 모바일 |
| --- | --- | --- |
| 이동 / 둘러보기 | WASD, 마우스 (화면 클릭 시 마우스 잠금) | 왼쪽 조이스틱 / 화면 드래그 |
| 도구 사용 | 왼쪽 클릭 (청소기·빗자루는 누른 채) | 사용 버튼 |
| 🥢 핀셋 | 1 | 하단 버튼 |
| 🌀 청소기 (카펫 위 안 됨, 오래 쓰면 롤러에 머리카락이 감김 → 빙빙 돌려 풀기) | 2 | 하단 버튼 |
| 🧹 빗자루 (쓸어서 모으기, 카펫 밖으로 빼내기) | 3 | 하단 버튼 |
| 🔍 돋보기 | Z / 오른쪽 클릭 (누르는 동안) | 켜고 끄기 |
| 🔦 손전등 (가구 밑 어두운 곳) | F | 켜고 끄기 |
| ✋ 카펫 걷기 / 화분 옮기기 (밑에 숨은 머리카락) | E (카펫·화분 조준) | ✋ 버튼 |
| 🔨 망치 · 🔥 라이터 · 😢 울기 (그 순간 이후) | 4 · 5 · 6 | 하단 버튼 |
| 💡 힌트 | H | 하단 버튼 |
| ⏸ 일시정지 (계속하기 · 소리 끄기 · 게임 끄기) | Esc | 우측 상단 ⏸ |
| ❓ 조작법 다시 보기 | 일시정지 중 ? | 우측 상단 ? |
| 🛌 엎드리기 (가구 밑 보기, 숨기) | C | 켜고 끄기 |

## 실행
빌드 과정 없는 정적 페이지입니다. `index.html`을 브라우저로 열거나 GitHub Pages(main 브랜치, 루트)로 배포하면 됩니다.
3D는 [three.js](https://threejs.org) r160을 `lib/`에 포함해서 씁니다 (MIT, `lib/three.LICENSE`).
주소 끝에 `?debug`를 붙이면 테스트용 `window.__game`이 열립니다.
