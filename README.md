# 여자친구 머리카락 청소하기 🧹

여자친구가 방을 돌아다니며 흘리고 다니는 머리카락을, 외출했다 돌아오기 전까지 한 가닥도 남김없이 치우는 웹 미니게임.

## 플레이 방법
1. 여자친구의 이름, 헤어스타일, 머리색, 피부톤, 옷 색깔, 빠지는 양(난이도)을 고른다.
2. 여자친구가 30초 동안 방을 돌아다니며 머리카락을 흘린다.
3. 여자친구가 외출하면 제한 시간 안에 남은 머리카락을 전부 치운다.

| 도구 | 키 | 설명 |
| --- | --- | --- |
| 🥢 핀셋 | 1 | 한 가닥씩 정확하게 집기. 카펫 위 머리카락은 핀셋으로만 치울 수 있음 |
| 🌀 청소기 | 2 | 누른 채로 쓸어 담기. 오래 쓰면 과열되어 잠깐 멈춤 |
| 🔍 돋보기 | 3 / Space | 켜고 끄기. 잘 안 보이는 잔머리를 확대해서 보여줌 |

## 실행
빌드 과정 없는 정적 페이지입니다. `index.html`을 브라우저로 열거나 GitHub Pages(main 브랜치, 루트)로 배포하면 됩니다.
